# ISO/IEC 42001 AI Management System Control Framework

## Overview

This repository contains an implementation of **ISO/IEC 42001:2023 Artificial Intelligence Management System (AIMS)** controls represented as atomic assessment controls.

The framework is designed to support:

- Evidence-based AI management system assessment
- AI governance evaluation
- AI risk management assessment
- AI lifecycle assurance
- Control scoring
- Assessment reporting
- Integration with governance, risk and compliance platforms

The implementation represents **ISO/IEC 42001 Annex A controls** and maps them exclusively to the **NCSC Cyber Assessment Framework (CAF)**.

No mappings to NIST AI RMF, ISO 27001, CIS Controls, OWASP or other frameworks are included.
