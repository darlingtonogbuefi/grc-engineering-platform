# ISO/IEC 27001:2022 Annex A Control Framework

## Overview

This repository contains an implementation of **ISO/IEC 27001:2022 Annex A security controls** represented as atomic assessment controls.

The framework is designed to support:

- Evidence-based information security assessments
- ISO/IEC 27001 control evaluation
- Security assurance activities
- Compliance reporting
- Risk-based remediation tracking
- Integration with governance, risk and compliance platforms


The implementation maps ISO/IEC 27001 Annex A controls exclusively to the:

**NCSC Cyber Assessment Framework (CAF)**


No mappings to the following frameworks are included:

- NIST Cybersecurity Framework
- CIS Controls
- OWASP
- COBIT
- Other ISO standards
