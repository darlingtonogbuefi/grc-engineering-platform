# SOC 2 Trust Services Criteria Control Framework

## Overview

This repository contains an implementation of the **SOC 2 Trust Services Criteria** represented as atomic assessment controls.

The framework is designed to support:

- Evidence-based security assessments
- SOC 2 readiness activities
- Control effectiveness evaluation
- Compliance reporting
- Risk-based remediation tracking
- Integration with governance, risk and compliance platforms


The implementation maps SOC 2 controls exclusively to the:

**NCSC Cyber Assessment Framework (CAF)**


No mappings to the following frameworks are included:

- ISO/IEC 27001
- NIST Cybersecurity Framework
- CIS Controls
- OWASP
- COBIT
- Other security frameworks
